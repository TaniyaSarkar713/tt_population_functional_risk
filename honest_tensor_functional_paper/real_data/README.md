# Application status

No real-data or LLM experiment is claimed. The working theorem assumes full independent Gaussian tensor replicates, known noise variance, a supplied Frobenius/rank outer class and a fixed orthogonal loading. No available dataset in the project has been shown to satisfy a scientifically defensible version of that model.

A suitable later study would require repeated calibrated measurements of the same tensor mean and an estimand fixed independently of those measurements. With LLM hidden states H_i^(ell) in R^(T_i x d), prompts, tokens and layers introduce different dependencies and dimensions. Simply stacking them does not yield the present experiment. A sampling model, valid noise envelope and loading-selection analysis must precede application claims.

The synthetic experiment already isolates the theoretical phenomenon. A forced application would weaken the current paper rather than fill a scientific gap.
