# Experimental figure design and audit plan

Skill applied: `/Users/taniyamac/.codex/skills/figure-designer/SKILL.md`.

1. Figure type: all figures are experimental-results or supporting analytic-bound figures. No invented motivated example is needed for this supplement.
2. Paradigm: loading profiles use line comparisons on log axes; pointwise dimension scaling uses paired line/error-bar panels; sparse caps use rate-normalized curves; real data use subject distributions and horizontal confidence intervals. Bars would hide trends or exaggerate comparisons with different assumptions. No illustrated pipeline is necessary for the statistical findings.
3. Layout: each figure is a two-panel 6.4-by-2.7-inch vector PDF/SVG. Loading panel one: cubic upper/lower proxies versus dimension for slow-decay profiles at fixed large budget; panel two: actual proxy ratios versus budget. Pointwise: root-MSE and interval width versus dimension, with Tucker/TT panels and measured MC uncertainty. Sparse: width and root-MSE normalized by their rate proxies over cap, with dimensions encoded by color and marker. Real data: primary clipped subject contrast distribution by group, and a separate full-range interval panel for direct finite-sample, approximate t, and calibrated projection uncertainty.
4. Labels: actual dimensions, cap, noise scale, microvolts, and explicit log scales. Colors use blue/orange/green/purple with distinct markers and line styles. Text is at least 8 points at full 6.4-inch placement. No color-only comparisons. The real-data interval panel retains the entire certified range; it must not crop wide intervals to emphasize the approximate positive result.
5. Tools: shared Matplotlib styles, code-generated PDF/SVG exports and tables. No manual adjustment of reported values. PNG preview only for visual inspection.
6. Universal audit: check vector objects/no embedded images, label counts, nonempty files, plotting data identity, and PDF pages. Visually inspect a rendered page. Captions state findings and include repetitions, uncertainty method, and theoretical scope. Do not label rate envelopes as observed interval widths or simulations.
7. Integrity: figure paradigms match outcomes; every axis and curve is named; no clinical or causal interpretation; no finite-sample coverage claim based on actual observed real-data coverage. Numeric QC is automated and typography/overlap checked visually.
8. Severity: final inspection status recorded in validation.json. No submission approval is requested by this design plan.

Final rendering: report figures occupy dedicated pages, each at full readable width with its complete caption. An initial float placement clipped the sparse figure; a Pandoc Lua filter now inserts page boundaries around each figure. Root inspection verified the corrected sparse figure, EEG distribution/interval figure, and report tables. Automated validation checks horizontal AND vertical text bounds in every PDF and verifies no raster images in the vector figures.
