# Repository instructions

## README updates before commits and pushes

The user requires the root `README.md` to be updated with project status and file organization every time changes are committed and pushed.

- Before each commit, update `README.md` to reflect the work being committed, the current research status, and the organization of added, moved, or removed files.
- Include that README update in the same commit as the changes it describes.
- Before pushing, check that the README still describes the final committed state; update it if additional work changed that state.
- Distinguish newly run checks from previously saved results, and distinguish the latest research stage from preserved earlier drafts.
- Use the existing `README.md`; do not create a separate lowercase `readme.md`.

This standing instruction comes directly from the repository owner.
